# GameHub-Analytics

# 🎮 Steam Analytics Dashboard

A modern web-based analytics dashboard for exploring Steam game data, player activity, pricing, reviews, and market trends.

> 🚧 **Project Status:** This project is currently under active development. Features, UI, and documentation are subject to change.

---

## 📖 Overview

The Steam Analytics Dashboard is designed to provide an interactive platform for analyzing Steam marketplace and player data. It aims to present insights through visual dashboards, charts, and searchable datasets to help users understand gaming trends and market behavior.

This project is also being developed as a portfolio project to demonstrate full-stack development and data engineering skills.

---

## ✨ Planned Features

- 🎮 Steam game search
- 📊 Interactive analytics dashboard
- 📈 Player count trends
- ⭐ Review and sentiment analysis
- 💲 Price history tracking
- 🏷️ Genre and tag analytics
- 🔥 Trending games
- 📅 Release timeline analysis
- 🔍 Advanced filtering and sorting
- 📱 Responsive UI
- 🌙 Dark mode interface
